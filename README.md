# ProperTickets website

This repository contains the ProperTickets static marketing website (`index.html`).

## Deployment
Connect this GitHub repository to the existing Vercel project `fair-ticketing` (project ID `prj_EEK6qUjL5JWhnhvh05qHmx0x3NKr`), production branch `main`, framework `Other`/no framework, root directory `/`.

## Artwork
The UK music hero artwork is an optimised WebP (442 KB), uploaded to Vercel's file storage and referenced via its returned CloudFront URL in `index.html`. An archival copy is stored in Google Drive as `ProperTickets-UK-Hero-Optimized.webp`. For permanent reliability, replace the externally hosted URL with a repository-owned asset at `assets/propertickets-uk-hero.webp` when a binary-capable GitHub upload method is available.
